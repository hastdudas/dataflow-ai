# supabase/

`schema.sql` を Supabase の SQL Editor に貼り付けて実行してください。
1回だけ実行すれば構いません。既にテーブルがある状態で再実行するとエラーになります。

作成されるもの:

- `public.profiles` — ユーザー1人につき1行。プランとStripeの情報を保持します。
- `public.usage_logs` — 処理1件につき1行。残り回数の集計と履歴表示に使います。
- `auth.users` への INSERT トリガー — 新規ユーザーに `profiles` の行を自動作成します。

RLS は両テーブルで有効です。読み取りは本人のみ、書き込みは
サービスロールキーを使うサーバー側コードからのみ行われます。
